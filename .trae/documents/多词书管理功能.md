# 多词书管理功能实现计划

## Context

WordMem 当前只支持单一词书（雅思词汇 4127 词），用户无法切换或导入其他词库。本次改动将：
1. 新增 CET4、CET6、考研词汇等内置词库（从 KyleBing/english-vocabulary 仓库转换）
2. 允许用户导入自定义词书（支持 JSON / TXT / CSV / Anki .apkg 等格式）
3. 在「词书详情」对话框中添加词书切换入口和导入入口
4. 提供词库下载网站链接
5. **每本词书独立保留学习进度**，切换不丢失

## 数据流设计

**词书注册表 + 独立进度**：
- `books` 表扩展字段记录来源（内置/导入）和文件路径
- `meta` 表的 `active_book_id` 记录当前选中词书
- `words` 表保留所有已注册词书的词（加 `book_id` 索引），切换时不需重新导入
- `study_state` 关联 `words.book_id`，每本词书的学习进度独立保留

**启动流程**：`build_context()` -> `BookManager.register_builtin_books()` 扫描 `book_registry.json` 注册内置词书 -> `ensure_default_active()` 设置默认词书 -> 仅导入活动词书的 words（首次启动）。

**切换流程**：点击词书卡片 -> 更新 `meta.active_book_id` -> 通知 MainWindow 刷新首页。**不清空学习进度**，旧词书的 words 和 study_state 保留在库中；若新词书的 words 尚未导入则先导入。

## 实现步骤

### 第一阶段：数据层 + 词库

1. **`src/wordmem/config/paths.py`** — 新增 `builtin_registry_file()`、`builtin_book_file(filename)`、`user_books_dir()`

2. **`src/wordmem/core/repository.py`** — 核心改动：
   - 扩展 `books` 表 schema：新增 `source TEXT DEFAULT 'builtin'`、`file_path TEXT`、`word_count INTEGER DEFAULT 0` 列
   - `_migrate()` 中检测并 `ALTER TABLE` 补齐新列
   - 新增方法：`list_books()`、`get_book_by_id()`、`get_active_book_id()`、`set_active_book_id()`、`get_active_book()`（替代旧 `get_book()`）、`is_book_imported(book_id)`、`count_words_in_book(book_id)`
   - `add_book()` 扩展签名：`add_book(name, description, source="builtin", file_path=None, word_count=0) -> int`
   - `get_new_words()` / `get_due_words()` / `get_all_words()` / `count_words()` / `count_learned()` 等方法增加 `book_id` 过滤（按活动词书 ID 查询）
   - `ensure_seeded()` 重写为委托 `BookManager`
   - 旧 `get_book()` 改为 `get_active_book()` 的别名（向后兼容）

3. **`src/wordmem/resources/data/book_registry.json`** — 新建内置词书清单：
   ```json
   {
     "default_book": "ielts_words.json",
     "books": [
       {"file": "ielts_words.json", "name": "雅思词汇", "description": "雅思核心词汇（含音标、释义与例句）"},
       {"file": "cet4_words.json", "name": "CET4 词汇", "description": "大学英语四级核心词汇"},
       {"file": "cet6_words.json", "name": "CET6 词汇", "description": "大学英语六级核心词汇"},
       {"file": "kaoyan_words.json", "name": "考研词汇", "description": "考研英语高频核心词汇"}
     ]
   }
   ```

4. **`src/wordmem/core/book_manager.py`** — 新建词书管理服务：
   - `register_builtin_books()` — 扫描 `book_registry.json`，把尚未注册的内置词书写入 `books` 表（幂等）
   - `ensure_default_active()` — 首次启动时设置 `active_book_id` 为默认词书，并导入其 words
   - `switch_book(book_id)` — 更新 `active_book_id`；若新词书 words 未导入则先导入
   - `import_book(path)` — 调用 `importers.parse_auto()` 解析文件 -> 复制 JSON 到 `user_books_dir()` -> 注册到 `books` 表 -> 可选立即切换
   - `delete_book(book_id)` — 仅允许删除 `source='imported'` 的词书；删除 words + study_state + books 记录 + JSON 文件
   - `list_builtin_books()` / `list_imported_books()` — 分别列出内置和导入词书
   - `get_active_book()` — 返回当前活动词书

5. **内置词库生成** — 用一次性脚本从 KyleBing/english-vocabulary 的 simple JSON 转换为 WordMem 格式：
   - `cet4_words.json`（约 4500 词）
   - `cet6_words.json`（约 5500 词）
   - 扩充 `kaoyan_words.json`（从 80 词扩到约 5500 词）
   - KyleBing 格式 `{"word":"x","translations":[{"translation":"y","type":"n"}]}` -> WordMem 格式 `{"word":"x","phonetic":"","meanings":[{"pos":"n.","meaning":"y"}],"examples":[]}`

### 第二阶段：格式解析层

6. **`src/wordmem/core/importers.py`** — 新建多格式解析模块：
   - 从 `apkg_to_words.py` 抽取 `clean_field()`、`parse_definition()`、`_POS_RE`、`_SOUND_RE`、`_TAG_RE` 等通用函数
   - 实现 5 个 parser + 1 个自动路由：
     - `parse_wordmem_json(path)` — WordMem 原生 JSON（含 `book` + `words`）
     - `parse_simple_json(path)` — KyleBing 格式（`word` + `translations[{translation, type}]`）
     - `parse_plain_txt(path)` — 每行 `word<TAB>释义`，调 `parse_definition()` 拆词性
     - `parse_csv(path)` — 通用 CSV（自动识别 ECDICT 表头 `word,phonetic,translation`）
     - `parse_apkg(path)` — Anki .apkg（复用 `scripts/apkg_to_words.py` 核心逻辑，返回 dict 而非写文件）
     - `parse_auto(path)` — 按扩展名自动路由；`.json` 内部根据结构自动判定 WordMem / simple
   - 所有 parser 返回统一结构：`{"book": {"name", "description"}, "words": [{"word", "phonetic", "meanings", "examples"}]}`

7. **`scripts/apkg_to_words.py`** — 重构为调用 `wordmem.core.importers.parse_apkg`，保留 CLI 入口

### 第三阶段：UI 层

8. **`src/wordmem/ui/views/dialogs.py`** — 重构 `BookInfoDialog`：
   - 顶部：当前词书信息（名称、描述、统计：共 N 词 · 已学 M · 待复习 K）
   - 中部：词书列表（滚动区），分「内置词书」和「我的导入」两组
     - 每本词书一行卡片：名称 + 词数 + 当前活动词书高亮（绿色边框 + "使用中"标签）
     - 点击非当前词书 -> `QMessageBox` 提示"切换到《XXX》？" -> `book_manager.switch_book(id)`
     - 导入词书行末有删除按钮（内置不可删）
   - 底部：「导入词书...」按钮 + 「下载更多词库」按钮（打开浏览器）
   - 新增 `book_switched = Signal()` 信号

9. **`src/wordmem/ui/views/import_dialog.py`** — 新建导入对话框（继承 `BaseDialog`）：
   - 文件选择行：路径输入框 + 浏览按钮（`QFileDialog`，过滤 `*.json *.txt *.csv *.apkg`）
   - 格式选择下拉：自动识别 / WordMem JSON / 简单 JSON / TXT / CSV / Anki .apkg
   - 词书名称输入框（默认从文件名推断）
   - 描述输入框（可选）
   - 下载链接区（3 个可点击链接）：
     - KyleBing/english-vocabulary（含 CET4/CET6/考研）
     - skywind3000/ECDICT（77 万词条 CSV）
     - mahavivo/english-wordlists（分类词库）
   - 「导入」按钮：用 `QThread` 后台解析（大文件不阻塞 UI），完成后刷新 `BookInfoDialog` 列表

10. **`src/wordmem/ui/main_window.py`** — `AppContext` 增加 `book_manager` 字段

11. **`src/wordmem/ui/views/home_view.py`** — `_open_book_info()` 连接 `book_switched` 信号；`refresh()` 改用 `get_active_book()`

12. **`src/wordmem/ui/views/word_list_view.py`** — `refresh()` 改用 `get_active_book()`

### 第四阶段：接线 + 验证

13. **`src/wordmem/app.py`** — `build_context()` 装配 `BookManager`，调用 `register_builtin_books()` + `ensure_default_active()`

14. 运行截图脚本更新 README 预览

15. 运行 pytest 确认测试通过

## 关键设计决策

- **保留各词书学习进度**：`words` 表保留所有词书的词，`study_state` 通过 `words.book_id` 天然隔离；切换只改 `active_book_id`，不清数据
- **用户导入的词书 JSON 复制到 `app_data_dir()/books/`**：不依赖原始文件路径
- **`book_registry.json` 而非硬编码**：未来添加新词书只需加 JSON 文件 + 改清单
- **Repository 查询按 `book_id` 过滤**：`get_new_words()` / `get_due_words()` 等方法加 `WHERE w.book_id = active_book_id` 条件

3. 切换到 CET4 词汇，确认进度不丢失（切回雅思时进度仍在）
4. 点击导入按钮，选择一个 TXT/JSON 文件，确认导入成功并出现在列表
5. 点击下载链接，确认浏览器打开 GitHub 页面
6. `pytest` 测试通过
